# ORBITA — 3D Solar System Explorer

Интерактивное WebGL-приложение для исследования Солнечной системы в настоящем 3D-пространстве.

## Запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Управление

- **Drag мышью** — вращение камеры;
- **колесо мыши** — приближение и отдаление;
- **W / A / S / D** или стрелки — полёт по пространству;
- **Space / Shift** — вертикальное движение;
- клик по объекту или выбор в панели слева — плавный перелёт к объекту;
- поиск на верхней панели — найти планету или Солнце.

## Возможности

- настоящее WebGL-поле с тысячами 3D-звёзд и частиц;
- процедурные объёмные планеты с освещением;
- Солнце с emissive-материалом и point light;
- орбиты, кольца Сатурна и Луна;
- скорости времени ×0.1 / ×1 / ×10 / ×100 и пауза;
- режимы исследовательского и реалистичного масштаба;
- качество графики Low / Medium / High;
- cinematic glassmorphism HUD;
- стартовый экран и сохраняемые настройки пользователя.

В проекте не используются внешние изображения: визуализации построены в Three.js, поэтому приложение может работать автономно после установки зависимостей.
